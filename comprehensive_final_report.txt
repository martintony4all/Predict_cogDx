TRANSFORMER FILES
--------------------
Each model directory now contains a 'transformers' subdirectory with:
  - standard_scaler.pkl: StandardScaler for numeric features
  - pca_model.pkl: PCA object (if USE_DOMAIN_INVARIANT_REPRESENTATION=True)
  - mice_imputer.pkl: MICE imputer (Imputed Model only)
  - numeric_features.pkl: List of numeric feature names
  - selected_features.pkl: List of all selected features
  - use_der_features.pkl: Flag indicating DER usage
  - imputation_info.pkl: Metadata about imputation settings
  - feature_info.pkl: Metadata about features

DEPLOYMENT INSTRUCTIONS
-------------------------
For production deployment on data WITHOUT DERs:
  1. Use REDUCED MODEL: simplest, but lowest accuracy
  2. Use IMPUTED MODEL: imputes DERs using MICE, better accuracy
     - Load transformers: scaler, pca (if used), imputer
     - Apply imputer FIRST to fill in missing DERs
     - Then apply other transformers (scaler, pca)
     - Finally run prediction
  3. Use FULL MODEL: only if DERs are available
