  - feature_info.pkl: Metadata about features

DEPLOYMENT INSTRUCTIONS
-------------------------
For production deployment on data WITHOUT DERs:
  1. Use REDUCED MODEL: simplest, but lowest accuracy
  2. Use IMPUTED MODEL: imputes DERs using MICE, better accuracy
     - Load transformers: scaler, pca (if used), imputer
     - Apply imputer FIRST to fill in missing DERs
     - Then apply other transformers (scaler, pca)
     - Finally run prediction
  3. Use FULL MODEL: only if DERs are available

Example deployment code for Imputed Model:
  imputer = joblib.load(f'{model_dir}/transformers/mice_imputer.pkl')
  scaler = joblib.load(f'{model_dir}/transformers/standard_scaler.pkl')
  pca = joblib.load(f'{model_dir}/transformers/pca_model.pkl')
  features = joblib.load(f'{model_dir}/transformers/selected_features.pkl')
  # Apply to new data
  new_data_imputed = imputer.transform(new_data[numeric_features])
  new_data[numeric_features] = scaler.transform(new_data_imputed)
  predictions = predictor.predict(new_data[features])
