  - feature_info.pkl: Metadata about features

DEPLOYMENT INSTRUCTIONS
-------------------------
For production deployment on data WITHOUT DERs:
  1. Use REDUCED MODEL: simplest, but lowest accuracy
  2. Use IMPUTED MODEL: imputes DERs using MICE, better accuracy
     - Load transformers: scaler, pca (if used), imputer
     - Apply imputer FIRST to fill in missing DERs
     - Then apply other transformers (scaler, pca)
     - Finally run prediction
  3. Use FULL MODEL: only if DERs are available
